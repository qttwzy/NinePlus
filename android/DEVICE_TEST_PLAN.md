# NinePlus Android 真机验证计划

每条用例都给出：前置条件、步骤、期望、失败信号、相关日志/诊断。
**危险操作必须在车辆停放安全、周围无人的条件下人工执行。**

---

## 1. 认证 / Session

### 1.1 全新安装登录
- **前置**：卸载 App；可用的 NinePlus Platform
- **步骤**：安装 → 打开「我的」→ 填服务器地址 → 测试 → 手机号+密码登录
- **期望**：登录成功，车控页出现车辆数据
- **失败信号**：登录成功但刷新仍提示未配置/未登录；HTTP 401
- **诊断**：设置页「推送设备/服务器」信息；logcat 过滤 `NinePlus`（不应打印完整 token）

### 1.2 进程重启后 session 仍有效
- **步骤**：登录成功后强杀 App（多任务上滑）→ 重新打开 → 手动刷新
- **期望**：无需重新登录，刷新成功（请求带 `X-NinePlus-Session`）
- **失败信号**：要求重新登录；401
- **诊断**：服务端 access log 应看到 session header

### 1.3 登出后 session 失效
- **步骤**：我的 → 退出登录 → 再次刷新
- **期望**：提示需要登录；请求不再带 `X-NinePlus-Session`
- **失败信号**：登出后仍能拉到车辆数据
- **诊断**：服务端 log

### 1.4 修改服务器地址后旧 session 作废
- **步骤**：登录 A 服务器 → 把地址改成 B 服务器
- **期望**：登录态清空，需重新登录
- **失败信号**：仍显示已登录账号

## 2. Dashboard

### 2.1 真实车辆刷新
- **前置**：绑定真实车辆
- **步骤**：车控 → 下拉/点击刷新
- **期望**：电量、续航、状态、更新时间合理
- **失败信号**：字段全为 `--` / 「接口未返回」
- **诊断**：诊断中心缓存计数；错误横幅文案

### 2.2 多车切换
- **步骤**：切换车辆 → 确认 Hero 信息变化 → 强杀重启
- **期望**：选中车辆持久化

### 2.3 离线 / 服务器不可用
- **步骤**：关闭网络或停掉 Platform → 刷新
- **期望**：保留上次缓存 + 错误提示；不崩溃
- **失败信号**：白屏或假空数据

## 3. 车辆操作（危险，注意物理安全）

> 执行前：车辆停放平稳、无骑行中人员、钥匙/遥控可用作后备。

| 操作 | 步骤 | 期望 | 失败信号 |
|---|---|---|---|
| 寻车铃 | 点「寻车」 | 车辆鸣笛 | 无声音且提示成功 |
| 上电 | 点「上电」→ 确认 | `pwr` 变为 1 | 仍显示已熄火 |
| 熄火 | 点「熄火」→ 确认 | `pwr` 变为 0 | 仍显示已上电 |
| 开座桶 | 点「座桶」→ 确认 | 座桶打开 | 无动作 |

**注意**：UI 用「上电/熄火」而非「开锁/关锁」。若 Platform `engine/start` 实际是解锁语义，请记录并回报。

## 4. Widget

| 场景 | 步骤 | 期望 |
|---|---|---|
| 冷启动 | 未打开 App 时添加小组件 | 显示「暂无车辆」或缓存 |
| 热数据 | 打开 App 刷新后看小组件 | 电量/续航/时间更新 |
| 刷新按钮 | 点「刷新」 | 短暂后数据更新 |
| 寻车按钮 | 点「寻车」 | 车辆鸣笛（低风险） |
| 危险按钮 | 点「开锁」区域 | **不会静默执行**；打开 App 并提示需在 App 内确认 |
| 外部攻击 | `adb shell am broadcast -a com.example.ninebotplus.WIDGET_ENGINE_START` | **无效**（receiver 未导出） |

**诊断**：`adb shell dumpsys package com.example.ninebotplus.debug | grep -A2 WidgetAction`

## 5. 骑行记录

### 5.1 前台记录
- **步骤**：记录页 → 开始记录 → 骑行 3 分钟 → 结束
- **期望**：速度、G、距离合理；结束后出现本地记录
- **失败信号**：G 全程 0；距离为 0

### 5.2 后台 2 分钟
- **步骤**：记录中切到桌面 2 分钟 → 回到 App
- **期望**：记录继续；通知栏有常驻「正在记录骑行」

### 5.3 锁屏 / 任务移除
- **步骤**：记录中锁屏 2 分钟；再试「最近任务上滑清除」
- **期望**：锁屏可恢复；任务移除后再次进入可恢复或明确提示（看 ActiveRideStore）
- **失败信号**：整条轨迹丢失

### 5.4 结束并查看地图
- **步骤**：结束记录 → 点进详情
- **期望**：显示轨迹折线、开始/结束标注、距离/均速/最快/最大 G

## 7. 通知

| 场景 | 期望 |
|---|---|
| Android 13+ 首次开启推送 | 真正弹出系统通知权限对话框 |
| 拒绝权限 | 设置页显示未上报/被拒，不再假装「已请求」 |
| 充电中 | 出现充电常驻通知（电量/续航/预计充满） |
| 充满 / 停止充电 | 通知自动消失 |
| 点击通知 | 打开 App 到车控 |

# NinePlus Android 真机验证计划（第三轮）

每条用例：前置条件、步骤、期望、失败信号、相关日志/诊断。
**危险操作必须在车辆停放安全、周围无人的条件下人工执行。**

---

## 1. 认证 / Session

### 1.1 全新安装登录
- **前置**：卸载 App；可用的 NinePlus Platform
- **步骤**：安装 → 「我的」→ 服务器地址 → 测试 → 手机号+密码登录
- **期望**：登录成功，车控页出现车辆
- **失败信号**：登录成功但刷新仍提示未登录；HTTP 401
- **诊断**：诊断中心；logcat 过滤 `NinePlus`（不应打印完整 token）

### 1.2 进程重启后 session 仍有效
- **步骤**：登录成功 → 强杀 App → 重新打开 → 刷新
- **期望**：无需重新登录，刷新成功（请求带 `X-NinePlus-Session`）
- **失败信号**：要求重新登录；401

### 1.3 登出后 session 失效
- **步骤**：我的 → 退出登录 → 刷新
- **期望**：提示需登录；请求不带 `X-NinePlus-Session`

### 1.4 切换服务器后 session 失效
- **步骤**：登录 A → 把地址改成 B → 刷新
- **期望**：登录态清空，请求不带 A 的 session
- **补充**：A → 清空地址 → B，同样不带 A 的 session

## 2. Dashboard

### 2.1 真实车辆刷新
- **步骤**：车控 → 刷新
- **期望**：电量、续航、状态、更新时间合理
- **失败信号**：字段全为 `--`

### 2.2 电源按钮（锁状态优先，`PowerActionDecision`）
| 遥测 | 按钮 | 期望 |
|---|---|---|
| `lock=1`（已锁） | 「上电」 | 可点，需确认 |
| `lock=0`（未锁） | 「熄火」 | 可点，需确认 |
| `lock=null, pwr=1` | 「熄火」 | 可点，需确认 |
| `lock=null, pwr=0` | 「上电」 | 可点，需确认 |
| `lock=null, pwr=null` | 「电源未知」 | **禁用** |

> 真机常见：已锁车辆仍报 `pwr=1`（ECU 唤醒）。此时按钮应为「上电」，不是「熄火」。

### 2.3 多车切换
- **步骤**：切换车辆 → 强杀重启
- **期望**：选中车辆持久化

## 3. 车辆操作（危险）

> 执行前：车辆停放平稳、无骑行中人员、钥匙/遥控可作后备。

| 操作 | 期望 | 失败信号 |
|---|---|---|
| 寻车铃 | 车辆鸣笛（无需确认，直接执行） | 无声音且提示成功 |
| 上电 | 点「上电」→ 确认框 → 确认后 `pwr`→1 / 状态变「已上电」 | 仍显示已熄火；或跳过确认框直接执行 |
| 熄火 | 点「熄火」→ 确认框 → 确认后 `pwr`→0 / 状态变「已熄火」 | 仍显示已上电；或跳过确认框直接执行 |
| 开座桶 | 点「座桶」→ 确认框 → 确认后座桶打开 | 无动作；或跳过确认框直接执行 |
| 取消确认框 | 任一危险操作点「取消」后 **不** 发指令 | 取消后车辆仍动作 |

**Widget 边界**：桌面「车控」不静默执行上电/熄火/开座桶，只打开 App 并弹「需要确认车控操作」。

## 4. Widget

| 场景 | 期望 |
|---|---|
| 冷启动添加组件 | 显示「暂无车辆」或缓存 |

## 5. 骑行记录

### 5.1 前台记录
- **步骤**：开始 → 骑行 3 分钟 → 结束
- **期望**：速度、G、距离合理；结束后出现本地记录
- **失败信号**：G 全程 0；距离为 0

### 5.2 进程死亡恢复（重点）
- **步骤**：开始记录 → 骑行 1 分钟 → `adb shell am kill`（或强杀）→ 系统重启 Service
- **期望**：通知栏仍有「正在记录骑行」；回到 App 能看到进行中记录；继续骑行有新点
- **失败信号**：记录停止、轨迹丢失、通知消失

### 5.3 后台 2 分钟
- **步骤**：记录中切桌面 2 分钟
- **期望**：记录继续；通知常驻

### 5.4 结束并查看地图
- **步骤**：结束 → 点进详情
- **期望**：地图显示折线 + 起终点圆点（绑坐标，非屏幕固定）、距离/均速/最快/最大 G

## 9. 凭证存储

- Keystore 可用：正常登录
- Keystore 不可用（部分模拟器）：release 明确提示「设备安全存储不可用」，不静默降级

## 10. 日志/隐私

```bash
adb logcat | grep -iE 'authorization|session|bearer|password'
```

不应出现完整 token / 密码。
